# Notes Feature (Note-Taking Group)

## Request
Explain how note-taking apps work and how Nocturne's Notes feature was implemented: the header button after Terminals, the side list that behaves like the Agents and Explorer panels, and notes that are mostly pasted in but can also be edited.

### Background: how note-taking apps work (not from code)
- `Inferred` (general knowledge, not from this repo): Notion, Apple Notes and Obsidian all have the same three parts. There is a **store** (Notion keeps blocks in a database; Obsidian keeps one Markdown file per note), a **list or sidebar** that shows notes newest first and has search, and an **editor** that saves on its own with no Save button. A note's title is either its own field (Notion, Obsidian file name) or its first line (Apple Notes).
- Nocturne uses the Obsidian-style store: one Markdown file per note, with a separate title field like Notion. When the title is empty it falls back to the first line, like Apple Notes. The rest of this report traces that design.

## Trigger Point
- Confirmed trigger: `nocturne.py:10175-10187`. The Agent view header builds one `Gtk.ToggleButton` per entry of `TAB_GROUPS`, sorted so `files` comes first. `TAB_GROUPS` lists `notes` after `terminals` (`nocturne.py:73`), so the Notes toggle sits right after Terminals. Its `toggled` signal calls `Window.group_toggled(tool, 'notes')` (`nocturne.py:10185`).
- Second trigger: Ctrl+Shift+J in `Window.on_key` → `workspace.show_notes()` (`nocturne.py:10855-10856`). It is inert in the Terminal view (`nocturne.py:10837-10838`).

## Confirmed Flow

### A. Opening the Notes group
1. `group_toggled(tool, 'notes')`. It returns early if the window is syncing buttons, has no workspace, or shows the plain Terminal view (`nocturne.py:10275-10278`). If the button was turned **off**, meaning Notes was already selected, it calls `workspace.toggle_notes()` (`nocturne.py:10283-10284`), re-syncs the buttons and returns (`nocturne.py:10285-10286`). Otherwise it calls `workspace.show_group('notes')`, then `refresh_strip()` and `sync_group_buttons()` (`nocturne.py:10287-10291`).
2. `Workspace.show_group('notes')`. It collects the pages whose `page_group()` is `'notes'` (`nocturne.py:5019`). `page_group` returns `'notes'` for any `Note` instance (`nocturne.py:4950-4951`).
   - If notes are open, it selects `last_page['notes']` or the first one, then runs `page_switched()` (`nocturne.py:5020-5025`).
   - If none are open, it sets `strip_group = 'notes'` (`nocturne.py:5026`) and builds the empty page: *No notes open* with **New note** (accent), **Paste as note**, and **Show notes** when the list is hidden (`nocturne.py:5035-5037`, `5040-5045`).
3. `refresh_strip()`. It keeps only pages of `strip_group` in the strip (`nocturne.py:5074`) and hides the session **+** for `files` and `notes` (`nocturne.py:5078`). It compares the visible side panel with `wanted_side()`: if they differ it calls `update_side()`, and if the notes panel is already shown it re-renders it (`nocturne.py:5079-5085`). Tab widgets are only moved when the visible set changes (`nocturne.py:5089-5095`).
4. `wanted_side()` maps `'notes'` to `'notes'` when `notes_open` is true (`nocturne.py:4685-4688`). `notes_open` starts as `True` (`nocturne.py:4390`).
5. `update_side()` creates `NotesPanel(self)` the first time and adds it to the shared `self.side` stack as `'notes'` (`nocturne.py:4699-4702`). It then shows the stack and places the paned (`nocturne.py:4706-4710`) and calls `notes_panel.render()` (`nocturne.py:4714-4715`). `self.side` is the only widget in `paned.pack1` (`nocturne.py:4384-4386`).
6. `toggle_notes()` flips `notes_open` and calls `update_side()`, which hides the stack when nothing is wanted (`nocturne.py:4722-4724`, `4703-4705`). This is the "click again hides or shows the list" behavior, the same as Agents (`toggle_sessions`, `nocturne.py:4717-4720`).
7. `show_notes()` (Ctrl+Shift+J). If Notes is already the group and no screen is open, it toggles the list. Otherwise it closes any screen, calls `show_group('notes')`, and reopens the list if it was hidden (`nocturne.py:4726-4738`).

### B. The notes list (NotesPanel)
1. Construction. The panel uses the `explorer` and `sessions-panel` style classes (`nocturne.py:3519-3520`), so it inherits the sessions panel CSS. The head has `NOTES` and two tools: `note-add` → `workspace.new_note` and `paste` → `workspace.paste_note` (`nocturne.py:3523-3533`). It also has a `Search notes` entry that re-renders on every change; Esc clears it (`nocturne.py:3535-3539`).
2. Rows. `row = SessionsPanel.row` (`nocturne.py:3515`) reuses the sessions row builder: a flat `session-row` button with a dot, an ellipsized title, a `menu-hint` and a tooltip, which calls `callback()` on click (`nocturne.py:3231-3250`). `note_row` adds a right-click handler that opens `workspace.note_menu(path, event, row)` (`nocturne.py:3547-3550`).
3. `render()`. It clears the list and reads the query (`nocturne.py:3554-3556`).
   - **OPEN** section: `note_pages()` sorted by `active_at`, newest first, filtered by title or full text (`nocturne.py:3562-3567`). The hint is `current` or `ago(active_at)`, and clicking calls `select_page`.
   - **NOTES** section: `list_notes(notes_dir(project))`, minus the open paths, filtered by content (`nocturne.py:3570-3575`). Clicking calls `open_note(path)`. It is capped at 500 rows (`nocturne.py:3573`).
4. `list_notes(folder)`. It scans `*.md` files (`nocturne.py:3326`) and re-reads a file only when its `st_mtime_ns` differs from `NOTE_CACHE` (`nocturne.py:3333-3336`). It returns `path`, `name`, `text` and `at`, sorted newest first (`nocturne.py:3339-3340`). The temporary `.md.tmp` files written by `save()` don't match `.endswith('.md')`, so they are never listed (`nocturne.py:3326`, `3437`).

### C. Creating a note: blank or pasted
1. `new_note(text='')`. It does nothing in the plain view (`nocturne.py:4841-4842`). The file name is `notes_dir(project)/<YYYYmmdd-HHMMSS>.md`, with `-2`, `-3`… added if that path is already open or on disk (`nocturne.py:4843-4848`). It calls `open_note(path)` (`nocturne.py:4849`). When `text` is given, it sets the buffer text, puts the cursor at the start and focuses the title (`nocturne.py:4850-4853`).
2. `paste_note()`. It reads the clipboard **asynchronously** with `request_text` (`nocturne.py:4862`). Text that is non-empty after stripping becomes `new_note(text)`; otherwise the status bar says so (`nocturne.py:4857-4861`).
3. `open_note(path)`. If the path is already open, it selects that tab (`nocturne.py:4816-4820`). Otherwise it builds `Note(self, path)`, reports `note.error` with `window.message` (`nocturne.py:4821-4824`), and closes any screen (`nocturne.py:4825-4826`). It builds a tab with a `note-tab` dot, `note.title` and a × (`nocturne.py:4827-4833`), then calls `add_page(...)` with `note_pressed` as the press handler (`nocturne.py:4834`) and selects the page (`nocturne.py:4835-4836`).
4. `add_page`. It wraps the tab in an `EventBox` handle, routes presses through `tab_pressed`, then `on_press` (`nocturne.py:4967`), queues a strip refresh whenever the title label changes (`nocturne.py:4972`), and appends to the notebook (`nocturne.py:4973`).
5. Notebook signals. `switch-page` → `page_switched(page)` (`nocturne.py:4347`). For a `Note` that sets `active_at`, `strip_group = 'notes'` and `last_page['notes']`, shows `'pages'`, and queues the strip (`nocturne.py:5003-5008`). `page-added` / `page-removed` → `sessions_changed()`, which persists the window state (`nocturne.py:4345-4346`, `5145-5150`).
6. `select_page` → `focus()` → `note.focus()` (`nocturne.py:4980-4982`, `5126-5127`). An empty note focuses the title; otherwise the text gets focus (`nocturne.py:3493-3494`).

### D. The Note page: load, edit, autosave
1. `Note.__init__`. It has a `note-title` entry with the `Untitled` placeholder; Enter moves focus to the text (`nocturne.py:3358-3362`). The body is a `GtkSource.Buffer` with the editor scheme, Markdown highlighting and word wrap (`nocturne.py:3363-3371`). The status bar has the project name, a flash label, a word and character count, and **Copy** (`nocturne.py:3375-3385`). Both the title entry and the buffer call `changed()` (`nocturne.py:3361`, `3387`). It then runs `load()` and `watch()` (`nocturne.py:3388-3389`).
2. `load()`. It reads the file and records `mtime`. A missing file counts as a new note with `''` (`nocturne.py:3399-3403`). Non-UTF-8 and other OS errors become `self.error` (`nocturne.py:3404-3407`). `split_note()` splits it, and the fields are filled while `loading=True` so that `changed()` ignores them (`nocturne.py:3408-3414`).
3. File format. `split_note`: a first line starting with `# ` is the title, and one blank line after it is dropped; otherwise the whole text is the body (`nocturne.py:3299-3304`). `join_note` collapses whitespace in the title and writes `# Title\n\nbody`, or the body alone when there is no title (`nocturne.py:3307-3309`).
4. Name shown in the tab and list. `note_name(title, body)` returns the title, else the first non-blank line cut to 60 characters with `…`, else `Untitled` (`nocturne.py:3312-3317`). `update_title()` sets `self.title`, which is the tab label (`nocturne.py:3470-3474`). That label's `notify::label` refreshes the strip and therefore the panel (`nocturne.py:4972`, `5084-5085`).
5. `changed()`. It sets `dirty`, `active_at` and the title, then restarts a **500 ms** timer for `save` (`nocturne.py:3420-3428`).
6. `save()`. It returns early if the note isn't dirty (`nocturne.py:3433-3434`). Otherwise it creates the folder, writes `<path>.tmp` and `os.replace`s it over the note, then records the new `mtime` (`nocturne.py:3435-3441`). On error it flashes a red message and keeps `dirty` (`nocturne.py:3442-3444`). On success it clears `dirty` and updates the count (`nocturne.py:3445-3446`).
7. Ctrl+S inside a note calls `note.save()` and flashes *Saved* (`nocturne.py:10806-10809`).

### E. Copying out, renaming, closing, trashing
1. **Copy**, from the status bar or the open note's menu: `copy_text()` puts the body (or the title if there is no body) on the CLIPBOARD (`nocturne.py:3481-3483`). For a note that isn't open, `copy_note(path)` reads the file and copies its body (`nocturne.py:4908-4919`).
2. **Rename**: double-clicking the tab focuses the title entry (`nocturne.py:4878-4880`). So do Ctrl+Shift+R (`nocturne.py:10853-10854`) and the menu's *Rename* (`nocturne.py:4890`). Typing in the title then runs `changed()` → autosave. The file name never changes, because the title lives inside the file (`nocturne.py:3307-3309`).
3. **Right-click menu** (`note_menu`): *Rename* or *Open*, *Copy text*, separator, *Close* (open notes only), *Move to trash* (`nocturne.py:4887-4906`).
4. **Close**: the ×, a middle click (`nocturne.py:4881-4882`), Ctrl+Shift+W (`nocturne.py:10863-10864` → `close_current`, `nocturne.py:4789-4794`), or `close_page` (`nocturne.py:4987-4988`) all end in `close_note()` (`nocturne.py:4864-4871`). That calls `Note.close()`, which cancels the timers and the file monitor, then saves when the text isn't blank and **deletes the file when it is** (`nocturne.py:3496-3510`). Finally it removes the page and destroys the handle.
5. **Trash**: `trash_note(path)` asks with `confirm()` (`nocturne.py:4928`), closes the note if it is open (which saves it first), sends the file to the trash with `Gio.File.trash` (`nocturne.py:4932-4936`), removes it from `NOTE_CACHE` and re-renders the panel (`nocturne.py:4937-4939`).

### F. Following edits on disk
1. `watch()` monitors the note's path (`nocturne.py:3449-3452`). Changes are debounced for 250 ms (`nocturne.py:3454-3457`).
2. `check_disk()` reloads only if `mtime` changed **and** the note isn't dirty (`nocturne.py:3459-3468`). Its own saves set `self.mtime` right after `os.replace` (`nocturne.py:3441`), so they don't trigger a reload. While you are typing, your text wins and the next `save()` overwrites the file.

### G. Persistence across restarts
1. `view_state()` adds `'notes': [p.path for p in note_pages()]` once the workspace has started (`nocturne.py:4941-4945`). `persist()` merges `view_state()` into each project, and into `home` for the Home workspace (`nocturne.py:10361-10365`). Home reads `notes` back on load (`nocturne.py:10265`).
2. `start()` reopens every saved note path that still exists, without taking focus (`nocturne.py:5114-5116`).
3. On window close, `confirm_window_close()` calls `save_notes()` on every workspace before `persist()` (`nocturne.py:10792-10794`). That runs `note.save()` for each open note (`nocturne.py:4873-4875`).
4. Removing a project calls `note.close()` for each open note (`nocturne.py:10527-10528`).

## Actor And Identity Context
- The note's file name, a timestamp ID, is made locally by `new_note()` from `datetime.now()` when the user creates a note. The user never types it (`nocturne.py:4844-4848`).
- The folder name comes from `project['path']`, which is the imported project's folder, through `notes_dir()` (`nocturne.py:3296`).
- Only the local Nocturne process reads and writes these files. Nothing is shared or sent over the network (`nocturne.py:3435-3441`, `3323-3340`).
